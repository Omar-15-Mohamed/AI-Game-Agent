# AI Game Agent — Minimax & Greedy Algorithm

## Overview
An AI-powered game agent that uses Minimax algorithm with alpha-beta pruning 
to create an unbeatable opponent.

## Algorithms Used
- Minimax with Alpha-Beta Pruning
- Greedy Search Strategy

## Technologies
- Python
- OOP Design Principles

## How It Works
The AI evaluates all possible game states using a decision tree, 
choosing the optimal move at every turn.
